# To -> Do

A simple and practical to-do list app built with Flutter — manage your tasks with reminders that actually ring like an alarm.

## Features
- Add tasks with a title, description, and due date/time
- Get an alarm-style notification (with sound) when a task is due
- Mark tasks as done with a checkbox
- Edit mode to delete completed or unwanted tasks

## Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed
- An Android device or emulator

### Installation
```bash
git clone https://github.com/yourusername/your-repo-name.git](https://github.com/sayahtarek/ToDo.git
cd your-repo-name
flutter pub get
flutter run
```

## Project Details
- **Framework:** Flutter
- **Language:** Dart
- **Packages used:** `alarm`, `permission_handler`
- **Extra assets:** `Alarm.mp3` (notification sound)
